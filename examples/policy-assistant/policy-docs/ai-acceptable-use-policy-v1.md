# AI Acceptable Use Policy (v1.0)

## 1. Purpose
Early guidance on generative AI tools while the AI Task Force builds a full program.

## 2. Approved tools
- ChatGPT (any plan) for drafting non-confidential text.
- GitHub Copilot for code.
- Cursor for code. **Client data may be used in Cursor as long as Privacy Mode is turned on.**

## 3. Data
Do not paste passwords or personal data into AI tools. Client data is allowed in tools that offer a privacy or no-training mode.
