# AI Tool Access Policy (v3.0)

## Summary of change
Starting November 1, 2026, access to Claude and Claude Code moves to **self-service in Okta**. Manager approval is no longer required for Claude Enterprise.

## How to get access (from November 1, 2026)
1. Open Okta and search for "Claude Enterprise".
2. Click **Request access**. Access is granted automatically after you complete the 15-minute AI Basics training.

Other tools (Copilot, Cursor, Gemini) still use the IT Service Portal request.
