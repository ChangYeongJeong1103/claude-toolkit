# Approved AI Tools

Last updated: 2026-08-15 · Owner: AI Task Force · Applies under AI Acceptable Use Policy v2.0

## 1. Approved tools

| Tool | Plan | Approved uses | Max data class |
|---|---|---|---|
| Claude | Enterprise (company SSO) | Writing, analysis, coding, research | Confidential |
| Claude Code | Enterprise (company SSO) | Coding on company repositories | Confidential |
| GitHub Copilot | Business | Code completion on company repositories | Internal |
| Cursor | Business, Privacy Mode on | Code on internal repositories only. Not for client data or client deliverables. | Internal |
| Gemini | Workspace (company account) | Email and docs inside Google Workspace | Internal |

## 2. Not approved
- ChatGPT free or Plus, or any personal AI account
- Browser extensions that send page content to an AI service
- Any AI tool not listed in Section 1

## 3. "Max data class"
The highest data class you may put into the tool. Definitions are in `data-classification.md`. Restricted data is never allowed in any tool on this list.

## 4. Requesting access
Submit the **AI Tool Access** request in the IT Service Portal: https://it.company.example/portal/ai-access
Your manager approves, then IT provisions the license, usually within 2 business days.
