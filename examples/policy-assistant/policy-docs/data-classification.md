# Data Classification Policy

Every piece of company data belongs to one of four classes.

| Class | Examples |
|---|---|
| Public | Press releases, published marketing pages |
| Internal | Org charts, internal wikis, non-client code |
| Confidential | Client names and contracts, campaign results for a client, pricing, client-provided data |
| Restricted | Household-level or device-level viewing data (ACR records, device IDs, IP addresses, household IDs), any personal data, raw panel data |

## Notes
- Aggregated viewing data that cannot be linked to a household or device (for example, totals by DMA with at least 50 households per cell) is **Confidential**, not Restricted.
- If you are unsure of a class, treat the data as the higher class and ask the Privacy Office.
