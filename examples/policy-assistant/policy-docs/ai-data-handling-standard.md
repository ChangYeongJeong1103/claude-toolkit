# AI Data Handling Standard

Status: Active · Effective: April 1, 2026 · Owner: Privacy Office with the AI Task Force

## 1. Rule
Before putting data into an AI tool, check two things:
1. the data class (`data-classification.md`)
2. the tool's "Max data class" (`approved-ai-tools.md`)

You may use the tool only if the data class is at or below the tool's max class (Public < Internal < Confidential < Restricted).

## 2. Restricted data
Restricted data (including household-level viewing data) must **never** be entered into any AI tool, including approved tools.
The only exception is the internal Secure Analytics Sandbox, and only with **written approval from the Data Protection Officer** for a specific project.

## 3. Client data
Client data is Confidential. It may be used only in tools whose max class is Confidential. Some client contracts forbid any AI use; check the contract or ask your account lead.

## 4. Incidents
If Restricted or Confidential data was entered into a tool that does not allow it, report it within 24 hours to privacy@company.example.
